# Changelog

All notable changes to Winget Dashboard will be documented in this file.

## [1.0.0] - 2026-10-08

### Initial Release

- First public release of Winget Dashboard.
- Added fast searching of the WinGet package catalog using a locally maintained catalog.
- Added application installation through WinGet.
- Added detection and management of available application updates.
- Added support for updating individual applications and multiple available updates.
- Added a view of installed applications with support for uninstalling selected software.
- Added reusable application lists for creating and managing custom software selections.
- Added local WinGet catalog creation and refresh functionality.
- Added application settings and automatic Windows language detection.
- Added support for English, Croatian, Slovenian, German, French, Spanish and Italian.
- Added English as the built-in fallback language.
- Designed the WPF interface for full keyboard operation and screen reader accessibility, with particular attention to NVDA.
- Added accessible keyboard navigation, predictable focus handling and keyboard shortcuts.
- Added support for Windows system colors, including Contrast and High Contrast modes.
- Added privilege elevation only when an operation requires administrator rights.
